# SPEC-007：小电视板级核验

- 日期：2026-11-03
- 前置：SPEC-005、SPEC-006；当前 Kimi 看板已恢复。
- 目标：建立可用于开发的引脚与外设基线，分别记录实测、匹配固件源码和未知项。

## 核验契约

1. 固定 QuotaClock commit `defb2c83986de0bf88b826a716f0d0415315d2f4`，对比公开归档镜像与本地已恢复镜像的程序、分区、资源区；NVS 单独比较，禁止把版本字符串相同当构建相同。
2. 优先使用现固件 HTTP 状态与低音量单声测试。若恢复旧网络配置，仅写 NVS `0x9000..0xdfff`，先备份当前内容并设备端校验；不写其它分区。旧 NVS 必须含有效配置、容量一致。无法联网时允许回滚或独立诊断。
3. 串口操作可能复位或暂时黑屏；所有退出路径复位回应用并释放端口。禁止更改 eFuse，禁止扫描、驱动未知 GPIO。
4. 独立诊断只能操作已获源码证据的显示/音频引脚，未知输入先保持高阻；Flash 改动须先备份并校验原区域，最后恢复原应用。RAM 诊断优先。
5. I2C ACK 只能证明地址响应；需读取芯片身份寄存器才能加强型号结论。音频驱动初始化成功不等于扬声器发声，需用户听感验收。屏幕需用户目视验收。
6. 网络、NVS 原始内容和 HTTP token 只在私有忽略目录或内存中处理；公开结果仅保存白名单字段。私有文件权限 600。
7. 用户确认外壳仅有一个触摸键。允许被动读取 GPIO 输入寄存器，观察用户触摸时的变化；不修改未知引脚的方向、上下拉、复用、输入使能或触摸外设配置。忽略已知显示、音频、USB、存储引脚。没有变化不能证明没有触摸硬件；有变化需重复关联才能提出候选引脚，不能直接认定芯片型号。
8. 连接中断时记录诊断未完成和异常类型；退出仍尝试复位、关闭串口并保存结果。复位调用返回只说明命令调用完成，不能作为 Flash 应用已启动的证据；启动需独立观察。清理异常不能覆盖原始诊断异常。
9. 已取得卖家 `时钟/S3版本/S3天气预报电路图.pdf` 原件（SHA256 `840b5900d0ba32935f07a8d8fa5649377ef34da617d5730c5b82056648db7a76`），TP_KEY 直接接 IO5。允许仅对 GPIO5 / TOUCH_PAD_NUM5 启用 ESP32-S3 原生电容测量，使用 IDF 5.1.2 `touch_sensor_v2/touch_pad_read` 官方例程的初始化方式；禁止遍历配置其它触摸通道。采样100ms、60秒，先空闲5秒，再按住2秒/松开3秒三次，保存原始计数及用户动作确认。无变化不自动认定硬件损坏；单次关联不替代产品手势验收。

## 开发准入

- 显示：恢复固件可见，源码对应关系及 GPIO 有明确证据；新驱动仍需实屏色序、边界、方向测试。
- 音频：确定总线与 PA 引脚，芯片探测通过；完整播放需实物听感。
- 输入：没有实测或原理图证据则禁用触摸功能，不能复用 GPIO4。
- 稳定性：记录观测时长与复位原因；短时通过不能宣称间歇黑屏根因已解决。
- 未能从软件确认的尺寸、物料、功耗、输入接线明确保留为未知。
