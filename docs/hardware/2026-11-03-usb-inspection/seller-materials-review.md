# 卖家资料核对与 GPIO5 原生触摸试验

- 日期：2026-11-03
- 输入：用户放入项目根目录的 `时钟/`、`1.54寸TFT/`。
- 原件索引与 SHA256：[seller-materials-manifest.json](seller-materials-manifest.json)。
- 结论：S3 整板图与已实测的显示、音频引脚一致，补齐 TP_KEY=GPIO5、录音数据输入 GPIO15、背光低有效电路。原理图接线可以作为诊断依据；原生触摸交互和录音仍未验收。屏幕具体料号尚未匹配。

## 1. 整板原理图

原件：[S3天气预报电路图.pdf](../../../时钟/S3版本/S3天气预报电路图.pdf)，1页。SHA256 `840b5900d0ba32935f07a8d8fa5649377ef34da617d5730c5b82056648db7a76`，与此前 QuotaClock AUDIO_BOARD.md 引用值相同，现已取得原件并审阅连线。以下是图纸声明，物料丝印与实际装配仍未检查。

| 信号 | MCU GPIO / 接线 | 证据等级 |
| --- | --- | --- |
| LCD_SDA / LCD_SCL | 1 / 18 | 原理图与既有实屏一致 |
| LCD_DC / LCD_RESET / LCD_BL | 17 / 6 / 2 | 原理图与既有实屏一致 |
| TP_KEY | 5，图中电极直接连 IO5，没有 TTP223 输出级 | 原理图证据；适用原生电容测量，交互尚未通过 |
| I2C_SDA / I2C_SCL | 40 / 39，外部上拉各10kΩ至3V3 | 原理图与 ES8311 身份实测一致 |
| I2S_MCK / I2S_BCK / I2S_WS | 38 / 16 / 7 | 原理图与既有播放一致 |
| I2S_DO | GPIO4 → ES8311 pin9 DSDIN | 播放已测；GPIO4不能用于触摸 |
| I2S_DI | ES8311 pin7 ASDOUT → GPIO15 | 原理图证据；录音未测 |
| ES8311_PA | GPIO8 → NS4150B CTRL | 原理图与既有播放控制一致 |
| USB D− / D+ | GPIO19 / 20 | 原理图；原生 USB 已枚举 |

ES8311 标注 I2C 地址0x18。图纸 U9=NS4150B，MIC3=GMI4015P-2C-42db，SPK1=FS-2308。麦克风信号经1µF电容耦合至 ES8311 MIC1P/MIC1N，正端有4.7kΩ上拉偏置。扬声器接功放差分输出；不能把任一输出当作地。图纸未给扬声器阻抗、功率，不由型号字符串推算。

背光 Q1=AO3401：source接3V3、gate接GPIO2、drain接FPC pin2，是 P 沟道高边开关。**按该电路推导为低电平导通，PWM duty越大，背光通电比例越小**。这与卖家源码 `analogWrite(2, 255-LCD_BL_PWM)` 一致，但未实测亮度曲线、极性变化或满亮功耗。PWM raw205不等于80%亮度。

USB为TYPE-C16PIN，CC各5.1kΩ下拉，DP/DN串联各27Ω；图中供电网为+5V与3V3，稳压器标注ME6217C33M5G和AMS1117-3.3。图纸未画电池充电或电量检测电路；这不等于已拆机确认无电池，也不构成整机额定电流或功耗测量。

图纸局部：[显示连接器与背光](s3-fpc-schematic-excerpt.png)、[Codec与麦克风](s3-codec-schematic-excerpt.png)。

参考原件：

- [T154B7-H12-07产品规格书](../../../1.54寸TFT/单屏-%20焊接12P-GMT154-07/T154B7-H12-07-产品规格书-.pdf)：第4页参数、第5页结构/引脚、第7页引脚定义。
- [T154H7-C12-01-V2产品规格书](../../../1.54寸TFT/单屏-插接12P-GMT154-01/T154H7-C12-01-V2-产品规格书.pdf)：第7页引脚定义；其页眉误写另一个料号，不能只读页眉认型号。

两份资料列出1.54英寸、IPS、240×240、ST7789，但**引脚顺序与整板图不同，不能据此认定本机就是其中一个型号，也不能直接替换屏幕**。目录中另有8/10针模块、15/16针单屏、带触摸屏版本；带TP屏的触摸程序不对应本机顶部单键。当前继续使用已实屏通过的 ST7789兼容、240×240、Mode3 基线。英寸、IPS、控制器后缀及机械尺寸保留待核对。

## 3. 卖家固件与说明书的适用边界

从 `时钟/S3版本/v1.4加气象预警（S3）.rar` 定向读取 `SmallDesktopDisplay/SmallDesktopDisplay.ino` 和 `libraries/TFT_eSPI/User_Setup.h`；不执行其中程序，不整包覆盖工程。源码使用GPIO2背光、`255-LCD_BL_PWM`反向映射，支持上述电路推导。主草图未找到顶部触摸处理，不能由此认定没有触摸硬件。

`SD2桌面时钟使用说明V1.1.pdf` 含通用配网说明与城市代码；其中ESP32-C3描述不能覆盖本机ESP32-S3实测。`SmallDesktopDisplay-main（参考此资料设计）.zip` 为较早参考设计，不把它与当前S3整板图混为一套物料。

## 4. 本轮原生电容测量

先更新SPEC-007/TASK-022，再将独立RAM诊断由“被动数字输入”改为“仅GPIO5原生电容测量”。初始化依据本地 ESP-IDF v5.1.2 官方 `examples/peripherals/touch_sensor/touch_sensor_v2/touch_pad_read`，只配置TOUCH_PAD_NUM5，不配置其它通道、不启用额外屏蔽电极。通过实际使用的 `soc/touch_sensor_channel.h` 及编译期断言确认通道5=GPIO5；不使用同SDK中遗留的 `soc/touch_channel.h` 映射。

- RAM镜像SHA256：`990ec21cba1db8531c1064e07e628fe7486e5f78cad4eec21c4c1ad7c89e71d8`。
- 采样100ms、600次、约60秒；600次读取全部返回ESP_OK。
- 原始计数16332～16400；前5秒均值16377.27、范围16362～16389。全程跨度约为空闲均值的0.4152%；这不是触摸识别率或可靠性指标。
- 用户确认完成顶部触摸三次，结束回到Kimi看板。动作没有同步时间戳，不能把某段细小起伏直接认成按下或松开。
- 诊断收到结束标记、复位方法返回、串口关闭。用户观察作为应用恢复证据另存；原始脚本的`flash_application_start_verified=false`保留，因为脚本本身不做启动验证。
- 没有写Flash/NVS，没有重复播放提示音。空闲堆282052B在日志中保持不变。

结果：[原始记录](ram-probe-native-touch-result.json)、[统计与用户确认](native-touch-assessment.json)。

**结论：已得到原理图接线和原生测量数据，但尚未建立三次按住/松开的可靠关联，产品触摸继续禁用。** 后续只在GPIO5上做带明确时间标记的灵敏度/电极接触校准，保留空闲对照；如仍无法分离，再核对顶部电极、连接及板版号，不扩展为未知引脚扫描。麦克风录音、亮度曲线、长期供电稳定性另行验收。
