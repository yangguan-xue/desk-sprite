# TASK-025：有声短片播放验证

- 输入：[SPEC-010](../specs/010-video-playback-probe.md)、现有显示/音频HAL、USB实机。
- 状态：完成。素材、构建、三轮播放、用户视听确认、原应用回刷及MQTT恢复检查均通过。

1. 素材工具：先建立损坏/错误格式/超大块拒绝测试；实现FFmpeg测试片生成及独立AVI校验。交付 `prepare_asset.py`、宿主测试；验证命令见SPEC-010。
2. 独立固件：固定官方依赖、复用HAL，加入JPEG解码、PCM输出和3轮统计；构建通过且镜像小于3MiB，不含凭据。
3. 实物试验：完整备份并验证、核对设备身份，仅写应用；抓取全部播放统计，恢复原应用并确认启动，关闭串口。
4. 记录去敏报告及复现命令，明确物理效果待用户确认，记录任何丢帧、耗时或同步限制。

实机修正：首轮用户确认有画面但无声音；核对官方音量范围及原已验收配置，移除额外的45%寄存器衰减，保留HAL默认0xBF和PCM峰值1200，重新构建并复测。

验证结果：修正后用户确认“能听到，画面也正常”；三轮各96帧、512000字节PCM，平均11.83fps，视频/音频/I2S错误0。两次试验均完成原应用校验、启动和MQTT订阅，串口关闭。详见 [实机报告](../docs/hardware/2026-11-05-video-playback.md)。

技术约束：只接受受信任、已验证测试片；不改产品固件和云端；不把回调日志当作用户看见/听见的证据。
